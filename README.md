# 华南师范大学明信片制作智能体 🎓

专属于华南师范大学学子的AI明信片制作工具，上传照片或输入个人信息，即可生成独一无二的华师开学纪念明信片！

## ✨ 功能特性

- 🎨 **AI人物创作**：根据名字、性别、爱好生成独特的人物形象
- 📷 **照片风格转换**：上传个人照片，AI生成别样画风的人物形象（**照片优先级最高**）
- 💌 **个性化祝语**：在明信片底部添加你的开学祝语
- 🏫 **华师专属背景**：以华南师范大学人工智能学院校园风光为背景
- 💾 **一键下载**：生成后可直接下载高清明信片图片
- 🌐 **Web访问**：提供友好的Web界面，可通过网址访问使用

## 🛠️ 技术栈

- **后端**: FastAPI + Python
- **AI图像生成**: 豆包SeeDream大模型
- **图像处理**: Pillow
- **对象存储**: S3兼容存储
- **前端**: 原生HTML/CSS/JS (响应式设计)
- **Agent框架**: LangChain + LangGraph

## 🚀 快速开始

### 环境要求

- Python 3.10+
- uv (Python包管理器)

### 安装依赖

```bash
uv sync
```

### 启动服务

```bash
bash scripts/local_run.sh -p 9000
```

访问 http://localhost:9000 即可使用明信片制作功能。

## 📝 使用说明

1. 打开网页，填写你的**名字**
2. 选择**性别**（男生/女生/其他）
3. 填写你的**爱好**（如：阅读、打篮球、弹吉他）
4. 写下你的**开学祝语**
5. （可选）上传你的**个人照片**，AI会根据你的照片生成动漫风格的人物形象
6. 点击「生成我的专属明信片」按钮
7. 等待15-30秒，即可看到生成的明信片，点击下载按钮保存

## 🌟 生成效果

明信片布局：
- **背景**：华师校园风光（学术厅+异木棉）
- **人物位置**：画面中右侧区域
- **信息展示**：左侧显示姓名和爱好
- **祝语位置**：底部半透明蓝色条中居中显示
- **水印**：右下角显示"华南师范大学·人工智能学院"
